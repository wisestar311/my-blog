# 테스트 실행 및 자동 수정 
다음 루프를 최대 3회 반복하세요.

1. 테스트 실행:'npm run test'
2. 모든 테스트가 통과하면 결과를 보고하고 종료
3. 실패한 테스트가 있으면:
	a. 실패 메시지와 스택 트레이스 분석
	b. 원인이 테스트 코드에 있으면 테스트 수정
	c. 원인이 소스 코드에 있으면 소스 수정
	d. 1단계로 돌아가서 재실행

3회 반복 후에도 실패하면 남은 실패 목록과 분석 결과를 보고하세요.
