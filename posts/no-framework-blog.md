이 사이트는 프레임워크나 번들러 없이 동작합니다. 구조는 이렇습니다.

1. `posts/` 폴더에 마크다운 파일을 둔다
2. 브라우저에서 `fetch`로 파일을 읽는다
3. 자체 작성한 파서가 마크다운을 HTML로 바꾼다
4. 결과를 페이지에 그대로 삽입한다

## 다크 모드

다크 모드는 CSS 변수와 `data-theme` 속성으로 구현했습니다.

```css
[data-theme="dark"] {
  --color-bg: #15161a;
  --color-text: #e8e8ea;
}
```

시스템 설정을 우선 따르고, 사용자가 직접 토글하면 그 선택을 `localStorage`에 저장해 기억합니다.

## 모바일 대응

`max-width`로 본문 너비를 제한하고, `@media (max-width: 768px)` 구간에서 여백과 글자 크기를 조정해 작은 화면에서도 읽기 편하게 만들었습니다.

배포는 정적 파일만 올리면 끝이라 GitHub Pages 같은 곳에 바로 올릴 수 있습니다.
