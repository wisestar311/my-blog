마크다운은 글의 *내용*과 *형식*을 분리해줍니다. 서식 버튼을 누르는 대신 이렇게 씁니다.

```markdown
# 제목
이건 **굵게**, 이건 *기울임*입니다.
```

## 장점

- 텍스트 파일이라 어디서든 열림
- git으로 버전 관리가 쉬움
- 특정 앱에 종속되지 않음

## 단점도 있다

물론 표나 복잡한 레이아웃은 워드 프로세서보다 불편합니다. 하지만 블로그 글처럼 텍스트 위주의 콘텐츠에는 충분합니다.

`inline code`처럼 짧은 코드도 자연스럽게 섞어 쓸 수 있고, 코드블록도 아래처럼 깔끔하게 표현됩니다.

```js
function hello(name) {
  return `안녕, ${name}!`;
}
```
